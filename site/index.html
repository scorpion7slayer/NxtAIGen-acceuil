BenchSift

BenchSift compare plus d'un millier de modèles d'IA selon leurs scores de benchmarks, leur prix et leur vitesse de génération. Vous pouvez les classer par code, mathématiques, vitesse, prix ou cybersécurité, puis en comparer plusieurs côte à côte. Les sources des données sont indiquées, pour choisir un modèle sur des chiffres vérifiables plutôt que sur des annonces.

NxtUpdate

NxtUpdate détecte les gestionnaires de paquets installés sur votre Mac — Homebrew, npm, pnpm, Yarn, Bun, pip et Cargo — ainsi que les mises à jour système de macOS. Une seule commande liste ce qui est obsolète et met tout à jour, depuis une interface dans le terminal ou en mode script. Un mode simulation montre ce qui changerait avant d'installer quoi que ce soit.

NxtGit

NxtGit est un client GitHub de bureau pour macOS et Windows, construit avec Tauri, React et Rust. Il réunit dans une seule fenêtre vos dépôts, issues et pull requests, la relecture de code et un assistant IA compatible avec plusieurs fournisseurs. Le projet est archivé : il ne reçoit plus de mises à jour, mais son code et ses dernières versions restent disponibles.
